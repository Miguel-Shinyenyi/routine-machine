# Routine Machine

An AI project that logs daily routines and learning, and over time learns to prioritize and
suggest, rather than just record.

Built to serve two things at once: actual daily consistency (sleep, exercise, house, cooking,
personal time, family, paid work, finances), and a portfolio project demonstrating AI
engineering, not just backend engineering.

This repo holds the code. Context, decisions, and progress notes live in the UMWAYI context
hub, at `projects/routine-machine.md`, which links back here.

## Why it exists

Directly from the person building it: "sometimes I feel like it's a lot so I end up doing
nothing." This system exists to counter that by leading with a little a day, tracked
honestly, rather than a plan that looks complete on paper and never gets touched.

## The three goals it feeds

- CMU masters application (Fall 2027 cycle)
- PostHog and other target roles
- Becoming a working AI engineer, not just claiming the title
